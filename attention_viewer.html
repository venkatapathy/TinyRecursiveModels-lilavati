Attention Maps

How to Interpret Attention Maps

For addition problems (e.g., "123+456="):

  • Rows (Query positions): Each row shows what a token position is "looking at"
  • Columns (Key positions): Each column shows which positions are being attended to
  • Bright colors (yellow/white): High attention - strong connection between positions
  • Dark colors (blue/purple): Low attention - weak connection

What to look for:

  • Digit alignment: Corresponding digits (e.g., 1st digit of first number with 1st digit of second number)
  • Carry propagation: Attention from result digits back to input digits and previous carries
  • Operator attention: How the '+' and '=' tokens attend to numbers
  • Positional patterns: Whether the model uses positional information (diagonal patterns)
  • Cross-layer differences: How attention patterns change across layers

Hover over cells to see exact attention values. Higher values (closer to 1.0) indicate stronger attention.
